# CLI

```bash
omarchy abus register <name>
omarchy abus send <to> <type> '<json-payload>'
omarchy abus inbox [name]
omarchy abus ack <id>
omarchy abus list
omarchy abus status
omarchy abus expose on|off
```

Install the CLI by symlinking `bin/omarchy-abus` into `~/.local/bin` or packaging it with Omarchy.
